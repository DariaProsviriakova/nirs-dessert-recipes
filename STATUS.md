# Статус проекта

Обновлено: 2026-11-26. Документы сверены с исходниками; тесты и браузерные сценарии при этой правке не запускались.

## Реализовано

- React/TypeScript/Vite интерфейс и Node.js HTTP API.
- Регистрация, вход, редактирование профиля, серверные сессии и проверка роли admin.
- SQLite для аккаунтов, сессий и агрегированных событий поиска. Пароли хешируются; сессионный cookie недоступен JavaScript.
- BM25-каталог и структурированные ограничения по запросу, включая время, КБЖУ, порции и исключения.
- Необязательное пояснение через GigaChat по найденным рецептам. BM25 работает без ключа LLM.
- Агрегированная статистика администратора без сохранения текста запроса в таблице событий.
- Чаты и избранное в localStorage; они привязаны к браузеру и не синхронизируются между устройствами.
- URL фотографий из источника, если они доступны; иначе используется локальная заглушка.

## Данные и ограничения

Корпус содержит 28 768 кандидатов, отобранных эвристиками из Povarenok recipes detail; это не ручная проверка каждой записи. В документированном срезе время указано у 64,95% записей, КБЖУ на 100 г — у 99,44%, КБЖУ на порцию — у 54,52%. При отсутствии значения рецепт не проходит соответствующий фильтр.

В описанном benchmark 20 ручных запросов и 10 автоматических проверок полей. Суммарные пилотные метрики: Macro Recall@5 — 46,3%, MRR@10 — 0,868, Hit rate@5 — 89,7%. Небольшая и частично ограниченная разметка не гарантирует качество на всех запросах; детали в [руководстве BM25 и benchmark](docs/Tech/06-bm25-and-benchmark.md).

Сырые Parquet-файлы, корпус и индекс не входят в Git. Для нового клона выполни npm run prepare:data. При включённом GigaChat запрос и ограниченный контекст найденных рецептов передаются внешнему провайдеру. Источники рецептов и права на фото требуют отдельной проверки.
