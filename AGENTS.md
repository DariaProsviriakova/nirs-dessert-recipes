# AGENTS.md — работа с проектом

## Назначение

Файл задаёт правила изменений кода и документации NIRS Dessert Recipes. В приложении используется название SweetMate. Перед задачей о пользовательском поведении нужно сверить реализацию с Product-документами и не описывать целевые функции как готовые.

## Документация

Product-раздел находится в `docs/Product/`:

- `01-context.md` — назначение продукта и ограничения текущего этапа.
- `02-users-and-scenarios.md` — роли и сценарии `GWT-NN`.
- `03-requirements.md` — проверяемые требования `REQ-NN`.
- `04-interface-and-behavior.md` — экраны, состояния, действия, доступность и адаптивность.
- `05-rules-and-data-meaning.md` — смысл полей и точные правила `RULE-GROUP-NN`.

Общее описание проекта находится в [README.md](README.md), текущее состояние — в [STATUS.md](STATUS.md). История изменений — в [CHANGE_HISTORY.md](CHANGE_HISTORY.md).

## Правила изменений

1. Перед работой прочитай корневой README, статус и индекс [Product](docs/Product/README.md), затем относящиеся к задаче страницы.
2. Если меняется пользовательское поведение, синхронно обнови сценарий, требование, интерфейсное описание или правило — только те документы, которые затронуты изменением.
3. Не переиспользуй и не перенумеровывай ID `GWT-NN`, `REQ-NN`, `RULE-GROUP-NN`, `GAP-NN` и `CH-YYYY-MM-DD-NNN`.
4. Неизвестное решение записывай вопросом `GAP-NN` в контексте. Не выдавай предположение за принятое решение.
5. После изменений запусти подходящую проверку; обнови статус и историю, если они затронуты.
6. Не вноси изменения в зону ответственности другой участницы без согласования.

## Ограничения прототипа

- Рецепты, поиск и ответы работают в браузере на демонстрационных данных; не называй их серверной базой, смысловым поиском или ответом LLM.
- Демо-регистрация хранит пароль открытым текстом в `localStorage`; её нельзя использовать с реальными учётными данными.
- Окно администратора открывается по фиксированному демо-аккаунту; серверных ролей, защиты данных и общей аналитики нет.
- Источники текстов и права на фотографии не подтверждены.
- Не добавляй реальные пароли и персональные данные в код, документацию или примеры.

## Стек и команды

Frontend расположен в `sweetmate-frontend/`: React, TypeScript и Vite.

```bash
cd sweetmate-frontend
npm install
npm run dev
npm run build
```
