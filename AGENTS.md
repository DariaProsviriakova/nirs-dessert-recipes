# AGENTS.md — работа с проектом

## Назначение и документация

Файл задаёт правила изменений NIRS Dessert Recipes; название интерфейса — SweetMate. Перед задачей прочитай корневой README, STATUS.md и [индекс Product](docs/Product/README.md), затем относящиеся к задаче Tech- и Service-страницы.

Product содержит исходную постановку и статусы, сверенные 2026-10-15 с frontend-прототипом. Актуальное состояние реализации смотри в STATUS.md и docs/Tech/.

## Правила изменений

1. При изменении пользовательского поведения синхронно обновляй только затронутые сценарии, требования, интерфейсные описания и правила.
2. Не переиспользуй и не перенумеровывай ID GWT-NN, REQ-NN, RULE-GROUP-NN, GAP-NN и CH-YYYY-MM-DD-NNN.
3. Неизвестное решение записывай как открытый вопрос, не выдавай предположение за принятое.
4. Обновляй STATUS.md и CHANGE_HISTORY.md, если они затронуты.
5. В протоколе указывай только реально выполненные проверки.
6. Не меняй зону ответственности другой участницы без согласования.

## Безопасная работа и ограничения

- Корпус рецептов отобран эвристически и не проверен вручную целиком.
- Наличие URL фотографии не подтверждает право на повторное использование.
- GigaChat необязателен; ключ хранится только в локальном .env. Не сохраняй ключи, реальные пароли и личные данные в Git.
- Чаты и избранное хранятся в браузере; аккаунты, серверные сессии и агрегаты событий — в SQLite.
- Демо-режим предназначен для локальной демонстрации, не для production.

## Стек и команды

Требуется Node.js 24 или новее. Первичная установка и загрузка локального корпуса:

    npm ci
    npm run prepare:data

Для разработки нужны два терминала: npm run dev в корне запускает backend; npm --prefix sweetmate-frontend run dev запускает Vite на 5173 и проксирует /api на backend. Для статического запуска сначала npm run build, затем npm start.

В package.json объявлены npm test, npm run test:e2e и npm run build. Статус документа сверен с текущей структурой 2026-11-26.
