## Продолжение диалога

| ID | Сценарий | Текущее поведение |
| --- | --- | --- |
| GWT-20 | Пример запроса | Кнопка подставляет «У меня есть банан и молоко. Что можно приготовить?» |
| GWT-21 | Подбор по всем продуктам | Каждый названный продукт должен входить в состав каждой карточки; дополнительные продукты перечислены отдельно |
| GWT-22 | Сравнение | «Где меньше калорий» сортирует показанные варианты по одной базе, по умолчанию на 100 г; отсутствующие КБЖУ не считаются нулём |
| GWT-23 | КБЖУ блюда | «У первого», выбор карточки или однозначное название определяют блюдо; ответ содержит четыре показателя и базу |
| GWT-24 | Порции | «На 6 человек» пересчитывает количества выбранного блюда; без выбора — показанных блюд с известным исходным числом порций |
| GWT-25 | Изменение пожеланий | «А без молока» ищет новые варианты с прежними продуктами кроме молока, исключая молоко и сгущёнку; новый явный список продуктов заменяет прежний |
| GWT-26 | История диалога | Контекст хранится в текущем чате и восстанавливается после перезагрузки; новый чат не наследует другой |

При неизвестном исходном числе порций математический пересчёт не выполняется, предлагается выбрать другой рецепт. КБЖУ без базы по умолчанию показываются на 100 г; числовой фильтр «до 200 ккал» требует уточнения базы. Это разные сценарии.

## Обсуждение выбранного рецепта

| ID | Сценарий | Текущее поведение |
| --- | --- | --- |
| GWT-27 | Размер порции и вопросы по рецепту | «Насколько большая порция?» и «порции» вызывают разговорный ответ по текущему блюду без повторных карточек. Число порций берётся из источника, неизвестный вес не выдумывается. При неоднозначности уточняется блюдо, затем «у второго» продолжает исходный вопрос. |

## Память блюд и время приготовления

| ID | Сценарий | Текущее поведение |
| --- | --- | --- |
| GWT-28 | Время текущего или другого блюда | «Сколько по времени готовит» отвечает по выбранному блюду; «приготовление второго блюда сколько по времени занимает» — по второму блюду подборки. Длительность берётся из источника, при отсутствии обозначается неизвестной. |
| GWT-29 | Возврат к ранним блюдам | Все показанные рецепты остаются в памяти текущего чата после новых подборок и reload. Можно назвать блюдо, сказать «второе из первой подборки», «первое из предыдущей подборки» или «второе блюдо в чате». |
| GWT-30 | Существующая история | Память восстанавливается из карточек, полных рецептов и КБЖУ старого чата без удаления сообщений. Новый чат не наследует блюда другого. |

Номер блюда без уточнения подборки относится к последней подборке, даже если после неё открыт один полный рецепт.
При совпадении нескольких названий система уточняет блюдо; недействительный номер не заменяется текущим выбранным.
