# NIRS Dessert Recipes — контекст продукта

Обновлено 2026-11-25. SweetMate помогает подобрать десерты по названию, продуктам и поддерживаемым ограничениям.
В текущей локальной версии интерфейс связан с сервером, готовым BM25-корпусом и адаптером GigaChat.

## Пользовательская ценность

Пользователь задаёт вопрос, получает до трёх карточек и открывает рецепт с ингредиентами, шагами и источником.
Гость видит только демонстрационный пример. Для поиска нужна регистрация или вход.

## Границы

- Аккаунты, сессии и агрегированная аналитика хранятся сервером.
- Чаты и избранное хранятся только в текущем браузере; синхронизации между устройствами нет.
- Рецепты и индекс создаются существующим модулем bm25/. Он не переписывался.
- GigaChat объясняет подбор по найденным записям. Для живого вызова нужен ключ в локальном .env.
- Без LLM доступны поиск, карточки и рецепты из корпуса.
- Нет редактора каталога, управления чужими аккаунтами, восстановления пароля по почте и публикации сайта.
- Ссылка на источник не означает проверку достоверности и прав. Неизвестные значения не выдумываются.

## Открытые вопросы

| ID | Состояние |
| --- | --- |
| GAP-01 | Корпус подготовлен участницей по RAG; источник известен. Массовая ручная проверка состава не выполнена. |
| GAP-02 | Используются поля готового BM25; дополнительных фильтров в интерфейсе нет. |
| GAP-03 | Используется готовый BM25 и его пилотный benchmark. Качество всех формулировок не гарантировано. |
| GAP-04 | Выбран GigaChat; живое подключение проверено с локальным ключом. |
| GAP-05 | Агрегаты реализованы; сроки хранения 7/90 дней — настраиваемое рабочее допущение до согласования командой. |
| GAP-06 | Фото корпуса не загружаются; права на старые фотографии гостевого примера остаются неподтверждёнными. |
