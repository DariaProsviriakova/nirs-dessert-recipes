# Product — индекс

## 1. Назначение документа

Это точка входа в продуктовые документы NIRS Dessert Recipes. Страницы разделены по теме: контекст, пользовательские сценарии, проверяемые требования, интерфейс и правила данных.

## 2. Документы

| Файл | Назначение |

| [05-rules-and-data-meaning.md](05-rules-and-data-meaning.md) | Значение полей и правила `RULE-GROUP-NN` |

## 3. Как читать

Для знакомства с продуктом открой [контекст](01-context.md). Чтобы увидеть пользовательские пути — [сценарии](02-users-and-scenarios.md). Для проверки конкретного поведения используй [требования](03-requirements.md); устройство экранов и состояний собрано в [описании интерфейса](04-interface-and-behavior.md). Точные правила поиска, ответа, доступа и хранения находятся в [правилах данных](05-rules-and-data-meaning.md).
