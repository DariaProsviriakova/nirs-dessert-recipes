## Что остаётся только на устройстве

| Файл/каталог | Что внутри | Как появится у другого участника |
| --- | --- | --- |
| .env и личные .env.* | Ключ GigaChat, личные настройки, данные создания администратора | Создать из .env.example и заполнить своими значениями |
| backend/.data/ | Рабочая SQLite аккаунтов/сессий/статистики и её WAL/SHM-файлы | Создаётся сервером автоматически |
| bm25/data/raw/ | Скачанный Parquet-датасет | npm run prepare:data |
| bm25/data/generated/ | Корпус, статистика и поисковый индекс | npm run prepare:data |
| bm25/data/benchmark-results/ | Сгенерированные результаты benchmark, если он запускался | При отдельном запуске benchmark |
| node_modules/, sweetmate-frontend/node_modules/, bm25/node_modules/ | Установленные зависимости | npm ci и шаг подготовки данных |
| sweetmate-frontend/dist/ | Собранный сайт | npm run build |
| backend/.test-artifacts/ | Тестовые базы, скриншоты, трассировки, временные живые проверки и проверка установки | Появляются при тестировании; для обычного запуска не нужны |
| playwright-report/, test-results/ | Отчёты тестовых инструментов, если созданы | Появляются при тестировании |
| Браузерные localStorage и cookies | Личные чаты, избранное и текущий вход | Не входят в файлы Git; у другого браузера своя история |
| Установленный Chromium для Playwright | Браузер тестового инструмента в системном пользовательском кеше | npx playwright install chromium |

.env.example является исключением из запрета на .env.*: образец **передаётся**, личные значения — нет.
package-lock.json передаётся, node_modules не передаётся.
Публичный .pem передаётся, поскольку это общий сертификат доверия, а не секрет.
Тестовые исходники передаются; результаты тестов, базы и одноразовые отладочные скрипты — нет.
Скриншоты, приложенные к переписке, и экспортированные копии инструкции вне репозитория не относятся к этому коммиту.

Отслеживаемые файлы bm25/ не изменены: исходные скрипты, веса, разметка, package.json и lock-файл остаются прежними.
Новые серверные обёртки catalog.mjs/search.mjs/recipe-data.mjs/recipe-memory.mjs влияют на отбор, адаптацию и диалог, но находятся в backend/.
Сгенерированные raw/generated не являются изменением отслеживаемых исходников BM25.

## Перед будущим push

1. Проверить git status --short --untracked-files=all и git diff --check.
2. Убедиться, что .env.example виден, а .env, рабочая база и артефакты исключены.
3. Передать все перечисленные исходники и документацию вместе, включая тесты и lock-файлы.
4. Выполнить проверки из инструкции запуска.
5. После командной проверки подготовить Pull Request в main и объединить его только по отдельному решению команды.

Команда git check-ignore .env backend/.data/sweetmate.sqlite bm25/data/generated/bm25-index.json.gz должна подтвердить локальные исключения.
Проверочная ветка: backend/gigachat-chat-integration. Pull Request и объединение в main в рамках этой отправки не создаются.

## Новому участнику

Следовать [02-running.md](02-running.md).
