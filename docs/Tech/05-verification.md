# Проверка проекта

## 1. Сборка

Из `sweetmate-frontend/` выполните:

```bash
npm run build
```

Скрипт сначала проверяет TypeScript (`tsc --noEmit`), затем собирает приложение Vite. Успешная сборка подтверждает компиляцию frontend, но не проверяет пользовательские сценарии и качество поиска.

## 2. Ручные проверки

- Откройте страницу на широком и узком экране; проверьте выдвижение боковой панели.
- Убедитесь, что гость видит пример и не может отправить запрос.
- В демо-профиле проверьте отправку запроса, карточки и открытие полного рецепта.
- Проверьте создание и удаление чатов, избранное, смену имени, смену демо-пароля и выход.
- Проверьте специальный демо-вход только на синтетических данных.

## 3. Известные пробелы

В `package.json` не определены автоматические тестовые скрипты. Нет тестов API, интеграционных проверок backend, benchmark поиска, проверки доступности скринридером или подтверждения прав на изображения. Не считайте успешную сборку проверкой этих свойств.

Текущие результаты ранее проведённых проверок отражены в [STATUS.md](../../STATUS.md); перед выпуском их следует выполнить заново.
