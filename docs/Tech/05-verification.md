# Проверка проекта

Первичная подготовка поиска из корня репозитория:

    npm ci
    npm run prepare:data

Корневые автоматические команды:

    npm test
    npm run test:e2e
    npm run build

npm test запускает Node.js тесты API, авторизации, поиска и диалога. npm run test:e2e запускает Playwright; нужен установленный браузер. npm run build проверяет типы и собирает frontend. Успешная сборка не подтверждает качество поиска, доступность интерфейса или права на фотографии.

Перед показом вручную проверь /api/health, гостевой и обычный вход, роль администратора, запросы по ингредиентам/времени/КБЖУ, пустую выдачу, фотографии/заглушки, сохранение чатов в том же браузере и узкую ширину экрана. Benchmark запускай отдельно; небольшой набор не заменяет ревью выдачи.

Фактические результаты с датами смотри в [Service/verification.md](../Service/verification.md). Список доступных команд не означает, что они уже выполнены.
