# Архитектура прототипа

## 1. Общая схема

SweetMate — одностраничное клиентское приложение на React 18 и TypeScript. Vite обслуживает разработку и собирает frontend. Серверного приложения в текущей структуре репозитория нет.

```text
Браузер
  └── React-приложение
      ├── App.tsx: точка входа React, экраны, состояние и поиск
      ├── styles.css: оформление и адаптивные состояния
      ├── recipeLibrary: каталог и демонстрационные ответы
      └── public/images/: изображения рецептов
          └── localStorage: демо-профиль, чаты, избранное, счётчики
```

## 2. Структура frontend

| Путь | Ответственность |
| --- | --- |
| `sweetmate-frontend/index.html` | HTML-точка входа Vite |
| `sweetmate-frontend/src/App.tsx` | Точка входа Vite/React, типы, каталог, поисковые функции, экранные состояния и UI |
| `sweetmate-frontend/src/styles.css` | CSS-переменные, компоновка, компоненты и медиазапросы |
| `sweetmate-frontend/public/images/` | Локальные изображения, доступные по `/images/...` |
| `sweetmate-frontend/vite.config.ts` | Конфигурация Vite и React-плагина |

Маршрутизация внешними URL не используется: чат, вход, профиль и окно администратора выбираются внутренним React-состоянием.

## 3. Поток обработки запроса

Обработчик отправки добавляет пользовательское сообщение, вызывает локальную функцию ответа, сохраняет результат в активный чат и записывает изменившееся состояние в `localStorage`. Поиск использует `recipeLibrary` из `App.tsx`; сетевого вызова не происходит. Подробное поведение описано в [Service](../Service/README.md).

## 4. Внешние зависимости

Runtime-зависимости: `react` и `react-dom`. Инструменты разработки и сборки: TypeScript, Vite и `@vitejs/plugin-react`. В package manifest не заявлены backend-клиент, UI-библиотека или поисковая библиотека.
