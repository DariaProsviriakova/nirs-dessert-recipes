# API и доступ

## API

В текущем репозитории frontend не использует HTTP API для чатов, поиска, рецептов, аккаунтов или аналитики. Поиск и ответы выполняются локально. Backend, сетевой клиент и внешняя LLM не подключены.

## Демо-аутентификация

Вход и регистрация используют данные текущего браузера. Email не подтверждается, серверная сессия или токен не создаются. Для обычного email демо-вход может сохранить введённый пароль в `localStorage`; фиксированный демо-аккаунт администратора распознаётся клиентским кодом.

## Ограничения безопасности

- Демо-пароль хранится открытым текстом в `localStorage`; нельзя использовать реальные или повторно используемые пароли.
- Значения в браузере пользователь может прочитать и изменить; разделение по email не обеспечивает конфиденциальность.
- Клиентское отображение окна администратора не проверяет серверную роль и не защищает данные.
- Удаление демо-профиля удаляет локальные записи браузера, а не серверную учётную запись.

Для реальной эксплуатации потребуется серверная аутентификация, безопасное хранение секретов, серверная проверка прав и политика хранения данных. Эти компоненты не входят в текущую реализацию. См. [Service: открытые вопросы](../Service/decisions.md#открытые-вопросы).
