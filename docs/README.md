# Документация проекта

## Назначение документа

Это указатель по документации репозитория. В `docs/` находятся продуктовые требования, описание сервиса и техническое устройство прототипа.

## Как читать

Для поведения продукта начни с [Product](Product/README.md). Описание пользовательских потоков и границ сервиса находится в [Service](Service/README.md), сведения об архитектуре, запуске и хранении данных — в [Tech](Tech/README.md). Актуальное состояние реализации находится в [STATUS.md](../STATUS.md).

## Разделы

- [Product](Product/README.md) — роли, сценарии, требования, интерфейс и правила данных.
- [Service](Service/README.md) — поведение сервиса SweetMate, запросы и ответы, состояния и ограничения текущего прототипа.
- [Tech](Tech/README.md) — устройство frontend, запуск, данные, доступ и проверки.
