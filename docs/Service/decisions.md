# Решения и вопросы

Файл фиксирует принятые решения и вопросы, по которым решение ещё не принято. Пока вопрос открыт, документы опираются на указанное рабочее допущение. После решения вопрос переносится в раздел «Принято», а затронутые документы обновляются; изменение записывается в [`../../CHANGE_HISTORY.md`](../../CHANGE_HISTORY.md).

Ответственные назначены по зонам работы, указанным в [README проекта](../../README.md); это не меняет распределение обязанностей команды.
