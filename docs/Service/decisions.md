# Решения и открытые вопросы

Решения датированы. D-02—D-04 описывают состояние на дату в октябре 2026 года, а не текущую архитектуру. Идентификаторы сохраняются и не переиспользуются.

## Принято

| ID | Дата | Решение |
| --- | --- | --- |
| D-01 | 2026-10-15 | Название интерфейса — SweetMate; учебный сайт подбора десертов. |
| D-02 | 2026-10-15 | Тогда поставка была frontend-прототипом без backend/API; историческая запись. |
| D-03 | 2026-10-15 | Тогда каталог и ответы были локальными, без BM25/LLM; историческая запись. |
| D-04 | 2026-10-15 | Тогда профиль, чаты и избранное хранились в браузере; историческая запись. |
| D-05 | 2026-10-16 | Документация разделена на Product, Service и Tech. |
| D-06 | 2026-11-26 | Текущая реализация включает React/Vite, Node.js API, SQLite, BM25 и необязательный GigaChat. |
| D-07 | 2026-11-26 | Датасет загружается с Hugging Face и обрабатывается локально; сгенерированные корпус и индекс не коммитятся. Фотофайлы не скачиваются, используются URL источника с заглушкой при отсутствии ссылки. |
| D-08 | 2026-11-26 | BM25 работает без GigaChat; при включении провайдер получает вопрос и ограниченный контекст найденных рецептов. |

## Открытые вопросы

| ID | Вопрос | Рабочее допущение | Ответственный |
| --- | --- | --- | --- |
| GAP-01 | Как подтверждать состав и происхождение рецептов? | Датасет — Povarenok; отбор автоматический и не подтверждает каждую запись. | Просвирякова Дарья; Маргорина Ирина для корпуса |
| GAP-02 | Какие поля и ограничения участвуют в поиске? | BM25 индексирует поля корпуса; запрос разбирает часть ограничений времени, КБЖУ, порций и исключений. | Маргорина Ирина |
| GAP-03 | Достаточно ли качества ранжирования? | Benchmark есть, но пул небольшой; пилотные метрики и ограничения описаны в bm25/README.md, порог качества не утверждён. | Маргорина Ирина |
| GAP-04 | Когда использовать LLM и какие данные передавать? | GigaChat включается настройкой и получает контекст найденных рецептов; правила эксплуатации ещё требуют решения команды. | Якубова Динара |
| GAP-05 | Каковы окончательные показатели и срок хранения аналитики? | События очищаются по ANALYTICS_DAYS, по умолчанию 90 дней; политика продукта не утверждена. | Якубова Динара |
| GAP-06 | Подтверждены ли права на текст и фото? | Ссылки на источник есть, право повторного использования отдельно не подтверждено. | Просвирякова Дарья |

Ответственные отражают рабочие зоны из [README](../../README.md), но не заменяют согласование команды.
