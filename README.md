# NIRS: рецепты десертов — SweetMate

Учебный сайт для подбора и просмотра рецептов десертов. Локально интегрированы интерфейс React, сервер,
готовый BM25 и адаптер GigaChat. Для живого объяснения GigaChat требуется собственный API-ключ.

## Запуск

Для проверки интеграции используйте ветку backend/gigachat-chat-integration, а не main:

~~~bash
git fetch origin
git switch --track origin/backend/gigachat-chat-integration
~~~

Если локальная ветка уже существует: git switch backend/gigachat-chat-integration.
Перед переключением сохраните свои изменения; не применяйте reset --hard для этого шага.


Полная инструкция для VS Code, WSL и новой установки: [Tech/02 — запуск](docs/Tech/02-running.md).
В ней описаны Node.js 24, зависимости, корпус, личный .env, GigaChat, тесты и типичные ошибки.

Если проект уже подготовлен, из корня:

~~~bash
nvm use
npm run build
npm start
~~~

nvm use относится к WSL с установленным nvm; при установленном Node.js 24 без nvm пропустите его.
Сайт: http://localhost:8000. Первая установка также требует зависимостей и индекса — см. полную инструкцию.
Каждый участник использует свой .env и ключ GigaChat. Без ключа доступны поиск и серверные пояснения.

Будущий состав отправки: [Tech/06](docs/Tech/06-release-files.md).
Интеграция подготовлена в ветке backend/gigachat-chat-integration для командной проверки. С main она ещё не объединена.

## Структура

- backend/ — сервер, авторизация, SQLite, связь с BM25 и GigaChat, тесты.
- bm25/ — подготовленная часть RAG и генерация локального индекса.
- sweetmate-frontend/ — исходный интерфейс с HTTP-интеграцией.
- docs/Product/ — сценарии, требования, поведение и правила.
- docs/Service/ — решения, источники и протокол проверок.
- docs/Tech/ — устройство, запуск, API, хранение и проверки.
- .env.example, .nvmrc, package.json, playwright.config.mjs — настройки, версия Node и команды.

## Разговор с помощником

Начните: «У меня есть банан и молоко. Что можно приготовить?».
Продолжайте в том же чате: «Где меньше калорий?» → «Выбираю первый» → «Покажи КБЖУ этого блюда» → «На 6 человек» → «А без молока».
Все названные продукты должны присутствовать в каждой карточке; дополнительные указаны отдельно.
Числовые ответы и пересчёт строятся сервером из источника. GigaChat помогает понять запрос и поддерживает разговор.
Подробности и ограничения: [проверка](docs/Tech/05-verification.md).
